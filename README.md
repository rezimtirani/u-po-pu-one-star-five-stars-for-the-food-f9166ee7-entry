One alien tourist's review of planet Earth: one star for the gravity, the shared air and the password-locked Wi-Fi — five stars for the tacos, which alone were worth the 40-light-year trip.

> One star: the gravity is a scam, the locals breathe the same air they fart into, and the Wi-Fi wants a password — but the tacos alone were worth the 40-light-year trip.

## How it works

`main.py` (Python 3 standard library only) writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, exactly one sentence, a one-star alien review of Earth that still compliments the food.

```sh
python3 main.py
```
